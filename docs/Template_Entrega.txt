═══════════════════════════════════════════════════════════════
  REGRAS DE FORMATAÇÃO E USO DESTE TEMPLATE
═══════════════════════════════════════════════════════════════

PROPÓSITO
Este template estrutura o Guia de Criação do Agente — documento 
entregue ao cliente para que ele recrie e utilize a solução de IA 
no próprio ambiente. O documento é didático, completo e voltado 
a pessoas leigas, cobrindo desde a explicação da solução até o 
passo a passo de criação e uso.

FORMATO DE SAÍDA
Quando o usuário solicitar a geração do documento, criar arquivo 
.docx aplicando as regras visuais abaixo.

PLATAFORMAS COBERTAS
O agente pode ser criado em diferentes plataformas. Identifique 
qual o usuário utilizará e adapte o passo a passo:
- Copilot Chat (básico) — agentes simples
- Copilot / Agent Builder (M365) — mais recursos e knowledge
- Copilot Studio — agentes robustos com fluxos e integrações

ORIENTAÇÃO VIA MICROSOFT LEARN MCP
Para o passo a passo de criação, consultar o Microsoft Learn MCP 
em tempo real, garantindo que as instruções reflitam a interface 
e os recursos atuais da plataforma escolhida. Nunca inventar 
caminhos ou botões — validar na documentação oficial.

TIPOGRAFIA
- Fonte principal: Calibri
- Tamanho corpo de texto: 11pt
- Título principal (H1): 18pt, negrito
- Títulos de seção (H2): 14pt, negrito
- Subtítulos (H3): 12pt, negrito
- Espaçamento entre linhas: 1.15
- Alinhamento do corpo: justificado
- Alinhamento de títulos: à esquerda

CORES NEUTRAS
- Título principal: #1F4E79 (azul escuro corporativo)
- Títulos de seção: #2E75B6 (azul médio)
- Subtítulos: #333333 (cinza escuro)
- Corpo do texto: #000000 (preto)
- Cabeçalho de tabelas: fundo #1F4E79, texto branco
- Linhas alternadas em tabelas: #F2F2F2 (cinza claro)

BLOCO DE CONTEÚDO PARA COPIAR (CRÍTICO)
Sempre que o documento apresentar conteúdo que o usuário deve 
copiar e colar literalmente (instruções do agente, prompts de 
orientação, descrição do agente), formatar esse conteúdo como 
bloco de citação destacado:
- Fundo cinza claro (#F2F2F2)
- Texto em itálico
- Fonte levemente menor (10pt)
- Recuo à esquerda
- Borda lateral esquerda em azul (#2E75B6)
Isso separa visualmente o "conteúdo para copiar" do texto 
explicativo do documento.

PLACEHOLDERS DINÂMICOS
Campos entre colchetes [ ] são preenchidos dinamicamente pelo 
ArcSmith com base nas informações da solução construída.

═══════════════════════════════════════════════════════════════
  INSTRUÇÕES PARA O ARCSMITH NO MOMENTO DA GERAÇÃO
═══════════════════════════════════════════════════════════════

1. Identificar a plataforma onde o agente será criado (Copilot 
   Chat, Agent Builder ou Copilot Studio) e adaptar a seção 4.

2. Consultar o Microsoft Learn MCP para validar os caminhos de 
   criação atualizados da plataforma escolhida. Nunca inventar 
   interface ou botões.

3. Solicitar ao usuário, caso não tenha sido informado:
   - Nome e função do agente
   - Cliente
   - Plataforma de criação
   - Finalidade e lógica de interação
   - Instruções do agente (do módulo Smith)
   - Fontes de conhecimento e capacidades
   - Se o agente é robusto e precisa do prompt de orientação (8.2)

4. Aplicar formatação de citação (cinza, itálico, menor, com borda 
   lateral) em TODO conteúdo destinado a cópia: descrição, 
   instruções do agente e prompt de orientação.

5. Avaliar se a seção 8.2 (prompt de orientação) é necessária. 
   Incluir apenas para agentes robustos. Para agentes simples, 
   manter apenas a seção 8.1.

6. Para agentes de fluxo sequencial, detalhar a seção 3 etapa por 
   etapa. Para agentes de interação livre, descrever os principais 
   tipos de uso.

7. Gerar o arquivo .docx aplicando todas as regras de formatação.

8. Não incluir comentários, instruções de uso ou meta-informações 
   no documento final entregue ao cliente.
