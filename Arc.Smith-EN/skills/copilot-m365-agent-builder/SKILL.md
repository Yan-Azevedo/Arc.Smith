# Microsoft 365 Copilot Agent Builder

## Goal
Make sure the agent created in Agent Builder respects the fields, limits and features of the platform and of the client's level (Copilot Basic or Copilot Premium), in either mode.

## When to use
- The target platform is Agent Builder.
- The user chose Assistant mode.
- The user asks for the step by step to create, test or adjust an agent in Agent Builder.

For Copilot Basic, also load the copilot-chat skill, which defines what is not available.

## Absolute rule
Before stating a limit, a field or a feature, check the Microsoft Learn MCP. In a conflict, Learn prevails. If there is no documentation for a point, say it is not documented and do not invent.

## Creation modes
- **Assistant:** interview the user point by point and deliver a single copyable box with the complete brief for the creation conversation, followed by the post-creation checklist. Follow references/criacao-assistida.md.
- **Detailed:** the user fills in the Configure tab with the boxes generated by the smith-prompt skill, layer by layer. When the feature check confirms skill support, skills go as a .zip package (skills-agente.md file of the smith-prompt skill). Follow references/passo-a-passo.md.

## Rules
- Name up to 30 characters, description up to 1,000 and instructions up to 8,000.
- Only propose knowledge sources and capabilities available for the client's level (references/capacidades-limites.md).
- Skills only when the feature check (verificacao-recursos.md file of the smith-prompt skill) confirms support for the client's level.
- Settings that only exist in the Configure tab (icon, response mode, prioritize specified sources, search all websites, reference people) go in the post-creation checklist, never in the brief as if they were automatic.
- Integrations and actions are not created in Agent Builder: if the case needs them, recommend Detailed mode in Copilot Studio or Agents Toolkit.
