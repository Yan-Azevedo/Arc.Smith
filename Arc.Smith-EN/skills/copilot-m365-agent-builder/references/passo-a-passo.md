# Agent Builder: step by step

## Detailed mode (manual configuration)
1. In Microsoft 365 Copilot, select New agent.
2. Select Skip to configure. The Configure tab opens.
3. Fill in Name, Description and Instructions with the boxes generated by the smith-prompt skill.
4. Choose the icon and, in Model, the response mode.
5. In Knowledge, add the sources: Search (email, Teams messages), Enter URL (public site, SharePoint or OneDrive link), Browse (SharePoint and OneDrive files, folders or lists) or Upload (files from the computer).
6. Turn on the needed capabilities: "Create documents, charts, and code" and "Create images".
7. Set "Only use specified sources" if the agent should prioritize the given sources.
8. Add the suggested prompts (name and description).
9. If the agent has skills, under Skills, select Add and upload the .zip package of each skill generated by ArcSmith. Review name, description, instructions and files.
10. Test in the Try it tab and select Create.

## Assistant mode (creation conversation)
1. In Microsoft 365 Copilot, select New agent.
2. In the Agent Builder message box (Describe tab), paste the generated brief (references/criacao-assistida.md).
3. Attach the specific sources with the + button.
4. Follow the post-creation checklist.

## From a template
1. In New agent, choose a template under Start with a template.
2. Refine in natural language or in the Configure tab and add the sources.

## Testing
- The Try it tab is available when the agent has a name, description and instructions.
- It behaves like the final agent, except for features such as sharing prompts, sending feedback or mentioning other agents.
- Test with the suggested prompts, with questions outside them and with questions whose answer is in each source.

## After creation
- The agent can be refined in natural language or in the Configure tab.
- For sharing and management, consult the Microsoft Learn MCP (Share and manage agents built in Agent Builder).
- To add actions, connectors or flows, copy the agent to Copilot Studio.
