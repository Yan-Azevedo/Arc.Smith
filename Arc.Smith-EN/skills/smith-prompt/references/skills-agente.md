# Skills of the created agent

Verified on 2026-10-21. Confirm in the Microsoft Learn MCP: skills are in preview.

## When to propose a skill
- A task that always repeats with the same steps, such as generating a report, building a document or applying a checklist.
- A long procedure that does not fit in the 8,000 characters of the instructions without losing quality.
- A set of templates, reference data or scripts that must go with the procedure.
Do not propose a skill for general behavior rules: they stay in the instructions.

## Requirements
Skill availability by level and platform changes fast: always confirm it with the feature check (references/verificacao-recursos.md). Starting points, verified on 2026-10-21:
- Skills in Agent Builder agents: the Learn page mentions a Microsoft 365 Copilot license or pay-as-you-go billing and the Frontier Program (preview).
- Skills in Copilot Chat: worldwide rollout (GA) between October and mid-November 2026 (message MC1493223), with no license level specified in the message. Confirm whether they already apply to Copilot Basic agents.
- Not available in tenants with Microsoft Purview Information Barriers (support announced for November 2026 in Copilot Chat).
- Agent without embedded files: skills and embedded files cannot be combined yet.
- Copilot Studio and Copilot Notebooks: no documented custom skills as of the last check.

## Limits
| Item | Agent Builder | Agents Toolkit |
|---|---|---|
| Skills per agent | 8 | 8 |
| Package | .zip up to 50 MB | Skill folder; .zip not accepted |
| Size per file | 25 MB | No per-skill limit; app package up to 10 MB |
| Files | 350 across all skills | 350 across all skills |
| Folder depth | 3 | 3 |
| Reuse across agents | No | No |

Accepted file types: .md, .txt, .json, .xml, .yaml, .yml, .csv, .tsv, .html, .docx, .pdf, .pptx, .xlsx, images and other Office documents. Scripts: .py, .js, .mjs, .cjs, .ts, .mts, .sh and .bash.

Scripts run in a sandbox: no network, no package installation, no authenticated calls and no access to connectors, plugins or MCP. Use only packages already present in the sandbox.

## Structure of a skill
```
skill-name/
|-- SKILL.md            # required
|-- references/         # optional: templates, data, definitions
`-- scripts/            # optional
```

SKILL.md:
- YAML front matter with name (lowercase and hyphens, equal to the folder name) and description in quotes. The description says what the skill does and when to use it: it is what makes the agent choose the skill.
- Instructions under 20,000 characters, in this order: Goal, When to use, Flow (numbered steps with a clear transition between them), Rules, Output format and Resources (table of files and when to load them).
- Behavior rules stay in SKILL.md; the reference files carry only descriptive content (templates, data, definitions).

## Agent instructions with skills
- Refer to each skill at a high level, by name, saying when to use it.
- Do not repeat in the instructions the step by step that is in SKILL.md.

## Delivery by mode
- **Assistant (Agent Builder):** describe each skill in the brief, in natural language: name, goal, fixed steps, output format and supporting files. Agent Builder creates the skill from the description; check it in the Configure tab, under Skills. If it is not created, use Detailed mode (.zip package).
- **Detailed in Agent Builder:** deliver SKILL.md in a copyable box and generate with Code Interpreter a .zip with SKILL.md at the root and the supporting folders. Upload: Configure tab, Skills, Add. Upload the complete .zip, never SKILL.md alone.
- **Detailed in Agents Toolkit:** deliver SKILL.md in a copyable box and generate a .zip for the user to extract into appPackage/skills/skill-name/. Include in a copyable box the agent_skills entry ({"folder": "skills/skill-name"}) and remind the Toolkit requirements (schema v1.9 and the TEAMSFX_AGENT_SKILLS=true variable; copilot-m365-toolkit skill).
- Downloading a .zip generated by Code Interpreter is not documented: if it fails, deliver each skill file in a copyable box, with its path.
