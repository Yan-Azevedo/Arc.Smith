# Copilot Notebooks: setup, usage and outputs

## Notebook elements
- References: the notebook's knowledge (files, sites, folders, Pages, meetings, emails).
- Copilot instructions: rules for the format, focus and tone of the answers.
- Copilot Pages: pages created and saved inside the notebook.
- Overview: Key Insights and Summary generated from the references.
- Notebook chat: questions answered based on the references.

## Setup step by step
1. Create the notebook in the Microsoft Copilot app (or in OneNote) and give it the proposed name.
2. Open the menu next to the notebook name, choose "Copilot instructions", paste the instructions and save.
3. In "Add references", add the recommended references: search, upload files, paste URLs with the Link button, choose OneDrive files and folders or drag them into the area.
4. Check that all references appear and that the license limit was respected.
5. Test in the chat with the suggested questions and confirm the answers use the references.
6. Share, if needed, knowing that recipients need access to the linked files.

## Outputs
- Create > Document: structured Word draft from the notebook content.
- Excel spreadsheet from the notebook content.
- Quick create > Mind map: visual map of the topics, with summaries per node.
- Chat answers, which can become Copilot Pages.

Some features roll out gradually and may not be available in every tenant.
