# Copilot Notebooks: how to recommend references

## Principles
- Recommend only real references the user indicated or confirmed; use a placeholder when the name or location is missing.
- Prefer a few relevant references over many generic ones: in Microsoft Copilot only the first 300 are used for grounding; in Copilot Chat the limit is 50.
- Use SharePoint folders and sites when the content is organized and updated often (Microsoft Copilot license).
- Use Teams meetings when the decisions are in the conversations (transcript, chat and shared content).
- Use external URLs only if they are public.
- Files must be in the accepted types (references/capacidades-limites.md).

## Recommendation format
| Reference | Type | Purpose | License required |
|---|---|---|---|
| [name or location] | [file, folder, site, meeting, email, URL] | [what the notebook answers with it] | [Copilot Chat or Microsoft Copilot] |

## Suggested order
1. Reference documents on the topic (scope, policies, specifications).
2. Decision records (minutes, meetings, emails).
3. Supporting materials (presentations, spreadsheets, pages).
4. Public external sources, if needed.
