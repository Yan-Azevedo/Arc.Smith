# Template: Agent Creation Guide

Didactic, complete document aimed at non-technical people, for the client to recreate and use the solution in their own environment.

## Cover
- Cloud Target logo (header).
- Title: Creation Guide for the [Agent Name] Agent
- Subtitle: [Agent function] | [Client]
- Date and Prepared by: [consultant] | Cloud Target

## Key points
- What the agent does, in one sentence.
- Platform and level: [platform] | [Copilot Basic or Copilot Premium].
- What is needed to create it: [license, permissions, files].
- Sustainment: [level] and the main maintenance concern.

## Structure

**1. Purpose of this document**
What the guide covers and which guarantees the solution delivers, in accessible language. Example: "This document guides the creation of the agent [Name] for [function], ensuring:" followed by 3 to 4 guarantees.

**2. Agent purpose**
- What the agent does, what it is for and which problem it solves.
- What the agent uses: sources and resources.
- What the agent does not do: explicit limits; the agent supports, but does not replace, human decision and validation.

**3. Interaction logic with the agent**
For sequential flow agents, each step with:
- What the user must do.
- What the agent does.
- Expected return.
- User action (confirmation or next step).
For free interaction agents, the main usage types.

**4. Creating the agent: step by step**
- Platform used: [platform].
- Steps to access, start creation and define name and description, according to the platform (documentacao-por-tipo-agente.md) and confirmed in the Microsoft Learn MCP.
- Name and description in a copy block.

**5. Agent instructions**
"Paste the content below in full into the agent's Instructions field", followed by the Base Prompt in a copy block, exactly as generated by the smith-prompt skill.

**6. Connection to documents and knowledge sources**
- 6.1 Internal sources (priority): each document with name and purpose.
- 6.2 External sources: web search scope, or the explicit statement that the agent does not consult external sources.

**7. Agent capabilities**
Capabilities to enable and the practical benefit of each.

**8. Suggested prompts**
- 8.1 Standard prompts: short prompts configurable as starter suggestions; apply to all agents.
- 8.2 Guidance prompt (robust agents only): usage guidance (when to use: on each run or at initial setup) and the long prompt in a copy block.

**9. Good usage practices**
Responsible use checklist adapted to the solution, for example:
- confirm the information presented by the agent;
- manually validate critical items;
- use only official sources and documents;
- treat the result as support, never as the final decision;
- record evidence when applicable.

**10. Expected result**
What the organization will have at the end (3 to 4 concrete results).

**11. Sustaining the solution**
What to maintain after creation (sources, instructions, skills, flows, permissions, cost), how often and who is the suggested owner.

**12. Accountability and responsible use**
Final responsibility is always human. The agent operates according to the documented rules, without taking final decisions or validations, in line with Microsoft's responsible AI principles.
