# Agent Builder: instruções

- O campo Instruções aceita até 8.000 caracteres. O Prompt-Base da skill smith-prompt já respeita esse limite.
- No modo Detalhado, cole o Prompt-Base direto no campo Instruções.
- No modo Assistente, o Prompt-Base vai dentro do briefing. Confira depois se o texto foi mantido.
- Se o agente tiver skills, cite cada uma em alto nível nas instruções, sem repetir o passo a passo delas.
- Escreva instruções coerentes com o que o agente tem configurado: não instrua o agente a usar fontes ou capacidades que não foram adicionadas.
- Cite as fontes de conhecimento pelo nome com que aparecem no agente.
- A descrição é usada pelo modelo para decidir quando usar o agente: seja curto, preciso e simples.
- Nunca inclua links nas instruções.
