# Copilot Notebooks: como recomendar referências

## Princípios
- Recomende só referências reais que o usuário indicou ou confirmou; use placeholder quando faltar o nome ou o local.
- Prefira poucas referências relevantes a muitas genéricas: no Microsoft Copilot só as 300 primeiras entram no grounding; no Copilot Chat o limite é 50.
- Use pastas e sites do SharePoint quando o conteúdo estiver organizado e for atualizado com frequência (licença do Microsoft Copilot).
- Use reuniões do Teams quando as decisões estiverem nas conversas (transcrição, chat e conteúdo compartilhado).
- Use URLs externas só se forem públicas.
- Arquivos devem estar nos tipos aceitos (references/capacidades-limites.md).

## Formato da recomendação
| Referência | Tipo | Para que serve | Licença necessária |
|---|---|---|---|
| [nome ou local] | [arquivo, pasta, site, reunião, e-mail, URL] | [o que o notebook responde com ela] | [Copilot Chat ou Microsoft Copilot] |

## Ordem sugerida
1. Documentos de referência do tema (escopo, políticas, especificações).
2. Registros de decisão (atas, reuniões, e-mails).
3. Materiais de apoio (apresentações, planilhas, páginas).
4. Fontes externas públicas, se necessárias.
